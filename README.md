# Boedoc — 코로나19 위험도 자가 진단 서비스

건강·활동 정보 입력에 따라 코로나19 위험도를 측정하고 선별진료소와 유의 사항을 안내하는 서비스입니다.
현대메디 백엔드 개발 인턴으로 참여했습니다.

- 기간: 2020.07 ~ 2020.08
- 인원: 7명 (Backend)
- 기술 스택: PHP, MariaDB, Apache

> 코드는 회사 자산이라 공개하지 않으며, 결과보고서는 당시 대표 허가 하에 포트폴리오 용도로 공개합니다.

## 담당 업무

- 자가 진단 문진 Step 3 및 결과 페이지 개발
- Database 구조 설계 및 데이터 구축
- Google Play 애플리케이션 배포·테스트·검수
